# 回望长征路 · 最终版 H5

这是一套可直接在手机浏览器打开的整合版互动 H5，已把原项目中的八个板块按叙事顺序串联，并重新统一了视觉、导航与转场。

## 打开方式

- 直接双击 `index.html` 即可离线预览。
- 手机上体验时，可在本目录启动一个本地预览服务，然后访问 `http://电脑局域网IP:4173`。

```bash
python3 -m http.server 4173
```

推荐在 iPhone / Android 手机的竖屏模式中浏览，也可在桌面浏览器中查看。

## 章节结构

1. 序章：山河回响
2. 第一板块：以时间开启回望
3. 第二板块：为什么出发
4. 第三板块：二万五千里路线互动页
5. 第四板块：长征战士画像
6. 第五板块：她们的长征
7. 第六板块：当代长征
8. 第七板块：长征精神视频与观后一问
9. 第八板块：终点、宣言、关键词与薪火寄语

## 主要交互

- 顶部目录、阅读进度与桌面端章节导航。
- 年份切换、历史背景节点切换、火炬点亮。
- 第三板块地图：点击 11 个路线节点、上一站/下一站、路线描线与图文同步切换。
- 第四板块：无名战士光点点亮、四路红军档案切换、年龄滑杆。
- 第五板块：六位女红军人物切换、移动端左右滑动、人物故事展开。
- 第六板块：长征精神卡片、塞罕坝前后对照拖拽、武汉人物切换。
- 第七板块：视频播放与重播、精神关键词展开、观后问答。
- 第八板块：身份宣言生成与复制、个人关键词选择、薪火寄语留言。
- 所有动画均支持系统“减少动态效果”设置。

## 素材说明

- 第三板块 11 张路线史料图按最终展示尺寸转码为 JPG，保证移动网络下的加载速度。
- 真实史料照片保留“史料照片”说明。
- 第五板块彩色情景画面明确标注“AI 情景再现”，没有与历史现场照片混用。
- 本作品为课程作业展示版本；公开传播或参赛前请按原项目素材清单核对图片授权。

## 文件

- `index.html`：完整页面结构。
- `styles.css`：统一视觉系统与响应式布局。
- `app.js`：全部章节数据与交互逻辑。
- `assets/`：页面所需图片、视频与本地字体。
